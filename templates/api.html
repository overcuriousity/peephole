API

The public endpoints of this node. No key needed. Everything public is delayed: a request shows up only {{ delay_minutes }} minutes plus a random 0–{{ jitter_minutes }} minutes after it arrived. Request contents, query strings and fingerprints are never public.

GET /api/blocklist

Threat intelligence for firewalls: the addresses that sent requests of a given severity in a time window, one address (or prefix) per line, as text/plain. Lines starting with # are comments. Recomputed at most once a minute per parameter set; the newest entries first, at most {{ crate::admin::blocklist::MAX_ENTRIES }}.

ParameterValuesDefault
hours1–{{ crate::admin::blocklist::MAX_HOURS }}: the window{{ crate::admin::blocklist::DEFAULT_HOURS }}
min_severity1–4: the least severity a request needs{{ crate::admin::blocklist::DEFAULT_MIN_SEVERITY }}
networks=1collapse a /24 (IPv6: /64) with {{ crate::admin::blocklist::NET_MIN_IPS }} or more entries into one prefixoff

An unusable value means its default, so a typo never makes a firewall script fail open. Never listed: Tor exits, verified crawlers, the addresses of this project's own nodes, and the operator's own and excluded networks. In a cluster, the list is drawn from every member's trap.

curl -fsS 'https://<this host>/api/blocklist?hours=48&min_severity=3&networks=1'

# nginx
curl -fsS https://<this host>/api/blocklist | grep -v '^#' | sed 's/.*/deny &;/' > /etc/nginx/blocklist.conf \
  && nginx -t && systemctl reload nginx

# nftables (an IPv4 set "peephole" in table inet filter)
curl -fsS https://<this host>/api/blocklist | grep -v '^#' | grep -v : \
  | sed 's/.*/add element inet filter peephole { & }/' | nft -f -

GET /api/stats

The wall's numbers as JSON: totals, unique IPs, countries, Tor exits, finished counter-scans, top IPs, countries and ASNs, the severity distribution, a timeline and a weekday × hour heatmap. Parameter range: 24h (default), 7d, 30d or all.

curl -fsS 'https://<this host>/api/stats?range=7d'

GET /api/map

Unique IPs per country (ISO 3166-1 alpha-2) as JSON, with the largest count. Parameter range as for /api/stats.

GET /api/countries

Country codes and their names as JSON; cached for a day.

GET /healthz

ok while the database answers, otherwise HTTP 503 unavailable. For load balancers and monitoring.
